zline Documentation

Fast, modern, and flexible pure-Zsh prompt engine.

Installation

With zload (recommended):

plugins=( casonadams/zline ) zload "${plugins[@]}"

Or manual git clone:

git clone https://github.com/casonadams/zline.git ~/.zline echo 'source ~/.zline/zline.zsh' >> ~/.zshrc echo 'zline preset powerline --transient' >> ~/.zshrc echo 'zline init' >> ~/.zshrc

Command Line Interface

  • zline preset <name>: Load built-in preset (powerline, lean, rainbow, pure).
  • zline style <name>: Set prompt styling flags (--transient, --ascii, --no-osc).
  • zline init: Pre-compile segments and attach lifecycle hooks.
  • zline bench [iters]: Run execution latency benchmark (< 1.5 ms assertion).
  • zline version: Print current version.

Built-in Segments

  • dir: Path shortening (--shorten 1), Git root anchor (--anchor git), path aliases (--alias github.com=gith).
  • git: Instant branch read (< 0.1 ms) + async dirty counts (--clean 2 --dirty 3).
  • status: Exit code failure badge (--hide-zero).
  • exec_time: Duration thresholding (--min 2).
  • prompt_char: Dynamic symbol with error and Vi-mode tracking (--symbol '❯').
  • venv: Virtualenv, Conda, and Poetry environment detection.
  • node: Node.js version detection from .node-version or .nvmrc.
  • k8s: Current Kubernetes context from ~/.kube/config.
