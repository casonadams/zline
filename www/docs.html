zline Documentation

Fast, modern, and flexible pure-Zsh prompt engine.

Installation

With zload (recommended):

plugins=( casonadams/zline ) zload "${plugins[@]}"

Or manual git clone:

git clone https://github.com/casonadams/zline.git ~/.zline echo 'source ~/.zline/zline.zsh' >> ~/.zshrc echo 'zline preset powerline --transient' >> ~/.zshrc echo 'zline init' >> ~/.zshrc

Command Line Interface

  • zline preset <name>: Load built-in preset or curated theme (powerline, lean, rainbow, pure, catppuccin, tokyonight, nord, gruvbox).
  • zline preset list: List all available layout presets and curated themes.
  • zline preset show <name>: Inspect preset configuration source.
  • zline style <name>: Set prompt styling flags (--transient, --transient-dir, --ascii, --no-osc, --frame, --connect).
  • zline init: Pre-compile segments and attach lifecycle hooks.
  • zline bench [--profile] [iters]: Run execution latency benchmark (< 1.5 ms assertion) or per-segment micro-profiling.
  • zline compare: Run comparative benchmarks against other prompt architectures.
  • zline doctor: Comprehensive diagnostics for shell version, UTF-8 locale, cache directory, and segments.
  • zline configure: Interactive configuration wizard.
  • zline migrate <p10k_file>: Automatically translate Powerlevel10k configurations to zline.
  • zline compile / clean: Manage compiled wordcode (.zwc).
  • zline update: Pull latest release and recompile bytecode.
  • zline notify [on|off|threshold|status]: Configure desktop notifications on long-running commands (OSC 777 / OSC 9).
  • zline version: Print current version.

Built-in Segments (34 Segments)

  • dir: Path shortening (--shorten 1), Git root anchor (--anchor git), path aliases (--alias github.com=gith), read-only lock indicator (--readonly-icon).
  • git: Instant branch read (< 0.1 ms) + async status badges (--clean 2 --dirty 3 --ahead 12), submodules (--submodule), stashes (--stash).
  • status: Exit code failure badge (--hide-zero, --color 9).
  • exec_time: Duration thresholding and precision (--min 2 --precision 2).
  • prompt_char: Dynamic symbol with error and Vi-mode tracking (--symbol '❯').
  • venv: Virtualenv, Conda, and Poetry environment detection.
  • node: Node.js version detection from .node-version or .nvmrc.
  • k8s: Current Kubernetes context from ~/.kube/config.
  • time: Local time formatted with pure Zsh prompt escapes.
  • jobs: Active background job count indicator.
  • aws: AWS profile and active region detection.
  • rust: Rust toolchain version from rust-toolchain or rust-toolchain.toml.
  • golang: Go version from go.mod.
  • terraform: Workspace from $TF_WORKSPACE or .terraform/environment.
  • docker: Active context from $DOCKER_CONTEXT or ~/.docker/config.json.
  • package: Application version from package.json or Cargo.toml.
  • user_host: User and hostname for SSH and root sessions.
  • battery: Battery charge percentage and charging state.
  • ruby: Ruby version from .ruby-version.
  • php: PHP version from .php-version.
  • java: Java version from .java-version.
  • dotnet: .NET SDK version from global.json.
  • load: System 1-minute load average with configurable warning thresholds (--warn 4.0).
  • ram: Memory utilization percentage with warning alerts (--warn 80).
  • nix_shell: Active Nix shell indicator from $IN_NIX_SHELL or $name.
  • direnv: Active Direnv environment indicator from $DIRENV_DIR.
  • lua: Lua runtime version from .lua-version or .tool-versions.
  • zig: Zig toolchain version from .zigversion or build.zig.
  • bun: Bun runtime version or indicator from bun.lockb or .tool-versions.
  • deno: Deno runtime version or indicator from deno.json or .tool-versions.
  • vi_mode: Modal editing mode badge (--normal NOR --insert INS --hide-insert).
  • gcp: Active Google Cloud project from $CLOUDSDK_CORE_PROJECT or config.
  • azure: Active Microsoft Azure subscription from $ARM_SUBSCRIPTION_NAME.
  • elixir: Elixir runtime version from mix.exs or .tool-versions.
