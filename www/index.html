Strict Zero-Fork Path

Renders prompts in under 0.7 ms without subshell forks. Built exclusively with native Zsh parameter expansions and memory-mapped builtins.

📦

100% Pure Zsh

No foreign C++ binaries or external daemon downloads. Works seamlessly across macOS, Linux, FreeBSD, Alpine/musl, and Termux with zero compilation.

🎨

Base16 Palette First

Standardizes on Term16 (0–15) colors. Adapts seamlessly to Catppuccin, Tokyo Night, Gruvbox, Nord, or Dracula without configuration tweaks.

🚀

Instant & Transient Prompt

Displays an instantaneous snapshot in 0.1 ms on shell launch. Collapses past prompts into a minimal symbol on Enter to keep your scrollback pristine.

🌐

Modern Terminal Protocols

First-class OSC 133 semantic prompt annotations for Ghostty, Kitty, WezTerm, and iTerm2. OSC 7 working directory inheritance and OSC 8 hyperlinks.

🧩

Declarative Array Syntax

Replaces 1,600 lines of uppercase global environment variables with a clean, readable, 15-line array configuration matching zload.
